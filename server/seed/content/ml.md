# 机器学习

## 第 1 章 学习范式与优化

### 1.1 监督学习与假设空间

监督学习从带标签的数据中学习输入到输出的映射。设输入空间为 X、输出空间为 Y，学习器的任务是在假设空间 H 中寻找一个函数 f，使它对未见样本也有良好的预测能力。分类与回归是最常见的两类监督学习任务。

学习机器学习之前需要具备三块基础：线性代数帮助我们理解特征空间、矩阵分解与模型参数；概率统计提供条件概率、贝叶斯公式和分布建模的语言；微积分提供梯度与链式法则，是反向传播的数学前提。Python 和 NumPy 则负责把公式落实成可运行实验。

假设空间过小会导致欠拟合，过大则容易记住训练集噪声。模型选择的目标不是让训练误差最小，而是在偏差与方差之间取得平衡。数据划分、特征工程与正则化共同决定最终泛化表现。

### 1.2 损失函数与经验风险

损失函数衡量预测值与真实目标之间的差异。回归任务常用平方损失，分类任务常用交叉熵损失；交叉熵与 softmax 的组合能把模型输出转化为类别概率。训练过程通过最小化训练集上的平均损失来近似最小化真实风险。

经验风险最小化只优化有限训练样本，因此需要警惕过拟合。可以使用独立验证集选择超参数，使用测试集完成最终评估。类别不平衡时，需要同时查看精确率、召回率、F1 与 AUC，而不能只看准确率。

损失函数也影响优化难度。平方损失对异常值敏感，Huber 损失更稳健；交叉熵在分类任务中具有较好的梯度性质。选择损失时必须同时考虑任务目标、数据分布与评价指标。

### 1.3 梯度下降与学习率

梯度下降沿损失函数负梯度方向更新参数。学习率过大时更新会震荡甚至发散，过小时收敛缓慢。随机梯度下降每次只使用一个小批量样本估计梯度，可以降低计算成本，并通过梯度噪声帮助模型跳出部分局部极小值。

动量法累积历史梯度方向，减少震荡；RMSProp 根据梯度平方的移动平均缩放每个参数的学习率；Adam 结合一阶与二阶矩估计，是深度学习中常见的默认优化器。优化器不能替代数据质量，训练曲线异常时首先要检查特征、标签与学习率。

为了判断收敛，应同时观察训练损失和验证指标。验证损失先下降后上升通常说明开始过拟合，此时可以使用早停、权重衰减或增加数据。一个清晰的优化实验应记录随机种子、批量大小、学习率和训练轮数。

## 第 2 章 泛化与模型选择

### 2.1 模型评估与交叉验证

模型评估的目标是估计模型在未知数据上的表现。固定划分训练集、验证集和测试集可以避免信息泄漏；测试集只能在模型与超参数确定后使用。小数据集可以使用 K 折交叉验证，让每个样本都有机会进入验证集。

分类任务可构建混淆矩阵，并计算精确率、召回率、F1 与 ROC-AUC。回归任务常使用均方误差、平均绝对误差和决定系数。评估指标必须与业务目标匹配，例如课程问答更关注答案忠实度与引用覆盖率，而非单纯的准确率。

数据泄漏是常见错误：标准化参数必须只在训练集上拟合，时间序列数据必须按时间切分，重复样本不能让同一实体同时出现在训练和测试中。可靠的实验还需要固定随机种子并重复多次。

### 2.2 正则化与过拟合

过拟合表现为训练误差很低而验证误差较高。正则化通过约束模型复杂度降低方差。L2 正则让参数趋向较小的值，L1 正则可以产生稀疏权重；Dropout 在训练时随机屏蔽神经元，迫使网络学习冗余表示。

早停根据验证集表现停止训练，是一种简单有效的正则化。数据增强、集成学习和降低模型容量也可以缓解过拟合。模型越复杂，需要的训练数据通常越多；在样本有限时，简单模型往往比深层模型更可靠。

诊断过拟合时，应同时观察学习曲线、特征数量和训练轮数。若训练集和验证集表现都差，可能是欠拟合；若两者差距不断扩大，应优先增加数据、增强正则化或减少模型复杂度。

### 2.3 集成学习与偏差方差

集成学习把多个基学习器的结果组合起来，降低单模型的不稳定性。Bagging 对训练样本重采样并并行训练，主要降低方差；随机森林在此基础上增加特征随机性。Boosting 依次训练弱分类器，使新模型关注前面模型的错误，通常降低偏差。

偏差描述模型系统性偏离真实规律的程度，方差描述模型对训练集扰动的敏感程度。模型选择就是在两者之间寻找平衡。交叉验证与学习曲线能帮助我们判断偏差或方差哪一个更主要。

集成并不总是有效：基模型过于相似时收益有限，弱模型噪声过大时也可能放大误差。实际应用中应优先保证数据质量与评估流程可靠，再考虑复杂的模型组合。

## 第 3 章 先修关系与学习路线

### 3.1 机器学习的先修知识与依赖顺序

机器学习的前置知识可以按依赖关系组织。第一步是 Python 与 NumPy，掌握数组、矩阵运算、广播和向量化；第二步是线性代数，理解矩阵乘法、特征值、奇异值分解及其在特征空间中的作用。

第三步是概率统计，重点是随机变量、条件概率、贝叶斯公式与常见分布；第四步是微积分与最优化，重点是偏导、链式法则、梯度下降和学习率。最后补充算法与数据结构基础，以便理解复杂度、索引与大规模数据处理。

推荐顺序为：Python / NumPy → 线性代数 + 概率统计 + 微积分 → 最优化方法 → 机器学习。缺少数学基础并不等于不能开始，但至少应能在遇到损失函数、梯度和模型评估时回到对应概念，而不是只调用现成 API。

### 3.2 AI 工程师学习路线与阶段目标

从零到 AI 工程师可以划分为四个阶段。阶段一用 4 到 6 周完成 Python、NumPy、线性代数与概率统计；阶段二是 6 到 8 周的机器学习，包括监督学习、损失函数、梯度下降、模型评估与集成学习。

阶段三进入深度学习与自然语言处理，学习反向传播、卷积与序列建模、Transformer 自注意力以及预训练语言模型；阶段四用 4 到 6 周完成 RAG 应用工程，包括文档切分、向量检索、重排序、提示模板、引用溯源和评测。

每个阶段都应该形成可验收的产物：阶段一完成一次手动线性回归；阶段二完成端到端表格数据项目；阶段三实现并解释一个自注意力模块；阶段四构建带引用与检索日志的课程问答系统。学习路线是参考，不是对个人能力的评价。
