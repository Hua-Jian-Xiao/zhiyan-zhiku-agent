# 操作系统

## 第 2 章 进程与并发

### 2.1 进程、线程与上下文切换

进程是操作系统进行资源分配的基本单位，拥有独立地址空间；线程是调度的基本单位，同一进程内的线程共享代码、数据和打开的文件。线程切换成本通常低于进程切换。

上下文切换保存和恢复寄存器、程序计数器和栈信息。频繁切换会增加系统开销；大量短任务、锁竞争和阻塞 I/O 都可能引起切换风暴。

现代程序常使用进程隔离安全与故障，使用线程或协程提高并发。协程是用户态调度，切换成本更低，但仍需要理解阻塞操作与调度器的配合。

### 2.2 CPU 调度

调度器决定哪个就绪进程或线程获得 CPU。先来先服务简单但容易产生长任务阻塞；最短作业优先能降低平均等待时间，却需要预知运行时间。时间片轮转适合交互系统。

优先级调度需要处理饥饿问题，可以使用老化机制逐渐提高长期等待任务的优先级。多级反馈队列结合时间片和优先级，根据任务行为动态调整调度策略。

调度目标包括吞吐量、响应时间、公平性和实时性，它们往往相互冲突。评价调度算法要结合场景，而不是只看单一指标。

### 2.3 同步、互斥与死锁

并发访问共享数据会产生竞态条件。互斥锁保证同一时刻只有一个线程进入临界区，信号量用于控制有限资源的访问，条件变量用于等待某个状态成立。

锁会带来开销、优先级反转和死锁风险。死锁的四个必要条件是互斥、占有并等待、不可抢占和循环等待。破坏任一条件即可预防死锁，也可以通过资源有序分配避免循环等待。

无锁编程借助原子操作和 CAS 提升并发性能，但实现复杂，容易出现 ABA 问题和内存序错误。工程上应优先使用成熟并发库，并用压力测试验证正确性。

## 第 4 章 内存与文件系统

### 4.1 虚拟内存

虚拟内存为每个进程提供独立地址空间，通过页表把虚拟地址映射到物理页。它提高了隔离性与内存利用率，并允许程序使用比物理内存更大的地址空间。

按需分页只在访问页面时加载数据；缺页中断会把页面从磁盘换入内存。页表项包含有效位、访问位和修改位，供置换算法决策。TLB 缓存最近使用的地址转换结果。

虚拟内存的代价是地址转换与缺页处理。内存访问局部性越好，缓存与 TLB 命中率越高。大页和预取可以降低转换与缺页开销。

### 4.2 页面置换算法

当物理页不足时，需要选择页面换出。FIFO 简单但可能出现 Belady 异常；LRU 依据最近访问时间淘汰最久未使用页面，效果较好但维护成本高。

CLOCK 算法用访问位近似 LRU，在实际操作系统中广泛使用。工作集模型根据近期访问判断进程当前需要的页面集合，防止抖动。

页面置换性能取决于访问模式。顺序扫描和随机访问的最佳策略不同，操作系统需要兼顾公平性、吞吐量与响应时间。

### 4.3 文件系统

文件系统把持久存储抽象为文件和目录，负责命名、权限、空间分配与数据检索。inode 记录文件元数据和数据块指针，目录把文件名映射到 inode。

日志文件系统在写入前记录事务日志，提高崩溃恢复能力；写时复制文件系统通过复制修改块保持一致性。缓存可以显著提高读写性能，但需要处理写回与断电一致性。

文件系统性能受块大小、碎片和访问模式影响。顺序读写通常快于随机读写，数据库与日志系统会根据负载选择 I/O 策略和持久化级别。
