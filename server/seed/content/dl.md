# 深度学习

## 第 1 章 神经网络基础

### 1.1 反向传播与计算图

神经网络由多层线性变换与非线性激活组成。前向传播把输入逐层映射为预测结果，损失函数衡量预测误差；反向传播利用链式法则，从输出层向输入层逐层计算损失对各参数的偏导。

计算图把运算组织成有向无环图，每个节点保存前向值，并在反向阶段接收上游梯度。Autograd 自动完成这一过程，使研究者可以专注模型结构。梯度消失和梯度爆炸是深层网络常见问题，原因包括激活饱和、权重初始化不当与连乘效应。

良好工程包括合理的参数初始化、批量归一化、残差连接和梯度裁剪。调试时可以先在小批量数据上过拟合，确认网络具备学习能力，再逐渐增加任务难度与训练数据规模。

### 1.2 激活函数与优化器

激活函数为网络引入非线性。Sigmoid 与 Tanh 在两端容易饱和；ReLU 计算简单，但可能出现神经元失活。GELU 和 SiLU 在 Transformer 与卷积网络中被广泛使用，能够提供更平滑的梯度。

优化器决定参数如何根据梯度更新。SGD 加动量在计算机视觉中表现稳定，AdamW 通过解耦权重衰减改善正则化效果。学习率调度包括余弦退火、线性预热和分段衰减，大模型训练通常需要预热阶段来避免早期不稳定。

训练稳定性与批量大小、学习率、权重衰减和数据精度相关。混合精度训练可以减少显存占用，但需要损失缩放。任何超参数调整都应记录实验配置，才能复现与比较。

### 1.3 卷积神经网络

卷积层通过局部连接和权重共享提取空间特征，显著减少参数量。多个卷积核可以学习边缘、纹理和更高层的语义模式；池化层降低空间分辨率，扩大后续层的有效感受野。

感受野描述一个神经元能够观察到的输入区域。堆叠小卷积核可以在保持较少参数量的同时增加感受野。残差连接让梯度能够跨层传播，使训练极深的网络成为可能。

卷积网络广泛用于图像分类、目标检测与分割。训练时可根据任务对图像进行裁剪、翻转和颜色扰动等数据增强；评估时要避免训练集与验证集来自同一场景造成数据泄漏。

## 第 2 章 序列、注意力与预训练

### 2.1 循环网络与序列建模

循环神经网络在时间步之间共享参数，适合处理文本、语音和时间序列。隐藏状态把历史信息传递到当前时刻，但普通 RNN 难以学习长距离依赖，并存在梯度消失问题。

LSTM 通过输入门、遗忘门和输出门控制信息流动，GRU 使用更少的门控结构。双向循环网络可以同时利用过去和未来上下文，但不适合严格的在线生成场景。

序列到序列模型由编码器和解码器组成，最初用于机器翻译。注意力机制允许解码器动态关注输入的不同位置，是 Transformer 出现之前处理长序列的重要方法。

### 2.2 Transformer 与自注意力

自注意力通过 Query、Key、Value 计算序列中任意两个位置的相关性。缩放点积注意力先计算 Q 与 K 的点积，再除以维度的平方根，经过 softmax 得到权重，最后对 V 加权求和。

多头注意力在多个子空间并行建模不同类型的关系，再拼接输出。位置编码为模型注入顺序信息；残差连接和层归一化保证深层训练稳定。相比循环网络，Transformer 支持并行计算，具有更强的长距离依赖建模能力。

自注意力权重大小只是模型内部计算的一部分，不等同于完整解释。理解 Transformer 还应结合掩码机制、前馈网络和训练目标。实际调试中可以绘制注意力热力图，并用消融实验检验其影响。

### 2.3 预训练与迁移学习

预训练语言模型先在大规模无标注语料上学习通用语言表示，再通过微调或提示适配下游任务。掩码语言建模、因果语言建模和序列到序列目标塑造了不同的模型能力。

微调可以用少量标注数据把通用模型迁移到特定领域；参数高效微调如 LoRA 只训练低秩增量矩阵，显著降低显存与存储成本。适配任务时要关注数据质量、灾难性遗忘和评估集泄漏。

预训练模型并非总是优于专用模型。推理成本、延迟、可解释性和领域覆盖都需要权衡。对于课程知识库问答，检索增强生成可以在不改动模型参数的前提下提升事实性与引用可追溯性。
