# 计算机视觉

## 第 1 章 图像表示与卷积

### 1.1 数字图像与颜色空间

数字图像是像素值的二维或三维数组。灰度图每个像素记录亮度，彩色图通常包含红、绿、蓝三个通道。像素值范围、颜色空间和归一化方式会直接影响模型训练。

RGB 适合显示，HSV 更适合颜色分割；Lab 空间试图让颜色差异更接近人类感知。图像预处理还包括尺寸缩放、裁剪、中心化和标准化。数据增强必须保持标签语义不变。

图像任务需要关注通道顺序、数据类型和取值范围。一个常见错误是在训练时归一化而在推理时忘记相同处理，导致模型效果突然下降。

### 1.2 卷积运算与特征提取

卷积核在输入图像上滑动，通过局部加权求和得到特征图。权重共享让同一个模式可以在图像任意位置被检测，大幅减少参数。多层卷积逐渐从边缘、纹理过渡到物体部件和语义概念。

步幅决定输出分辨率，填充控制边界信息，空洞卷积可以在不显著增加参数的情况下扩大感受野。批归一化与残差连接提升训练稳定性。

卷积网络不是越深越好。小数据集上过深的网络容易过拟合；可以借助迁移学习、数据增强与正则化提升泛化能力，并通过可视化特征图检查模型是否关注合理区域。

### 1.3 感受野与网络结构

感受野表示网络中一个神经元对应的原始输入区域。多个小卷积核串联可以在扩大感受野的同时降低参数数量。深层特征通常具有更大的感受野，适合表示整体物体语义。

池化层降低特征图尺寸并增强局部平移不变性，但过度下采样会损失空间细节。目标检测和分割任务需要多尺度特征融合，以兼顾语义信息与定位精度。

设计网络结构时应同时考虑感受野、计算量和显存。对于移动端部署，可以使用深度可分离卷积和轻量网络；对于高精度任务，则可以使用更大输入和更密集的特征金字塔。

## 第 5 章 视觉任务与多模态

### 5.1 图像分类

图像分类为整张图片预测一个或多个类别。数据质量、类别平衡和标注一致性通常比模型结构更重要。训练集需要覆盖不同光照、角度和背景，避免模型学习到与标签无关的捷径。

交叉熵是常见分类损失；多标签任务中每个类别独立使用 sigmoid。评价指标包括 Top-1、Top-5、精确率、召回率和混淆矩阵。类别不平衡时可以使用重采样、类别权重或 focal loss。

模型部署前应进行校准和分布偏移测试。真实场景中的分辨率、设备与训练集可能不同，仅凭离线准确率无法保证线上效果。

### 5.2 目标检测

目标检测需要同时预测物体类别与边界框。两阶段方法先生成候选区域再分类回归，单阶段方法直接在特征图上预测。锚框、中心点与查询式检测器代表不同设计思路。

IoU 衡量预测框与真实框的重合程度，NMS 用于去除重复检测。平均精度 mAP 综合考虑不同类别和 IoU 阈值，是目标检测的主流指标。

检测任务容易出现小目标漏检、类别不平衡和标注噪声。多尺度特征、数据增强和难负样本挖掘可以提升鲁棒性，但必须通过验证集确认收益。

### 5.3 语义分割与多模态

语义分割为每个像素分配类别，实例分割进一步区分同类不同实例。编码器—解码器结构通过跳跃连接融合浅层空间信息与深层语义信息，常用于医学影像与自动驾驶。

视觉—语言模型把图像编码与文本编码映射到共享空间，支持图文检索、图像描述和视觉问答。构建多模态 RAG 时，应保留图像来源、区域与文本说明，以便生成可追溯的证据。

评价多模态系统不能只看文本相似度，还要检查视觉证据是否真的支持结论。对于课程知识库，图像、公式和文字之间的对应关系是重要的元数据。
